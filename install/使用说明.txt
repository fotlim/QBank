题库工坊 QBank —— 绿色版使用说明
====================================

一、怎么开始
------------
1. 把整个文件夹解压到任意位置（U 盘、桌面、D 盘都行），双击 QBank.exe 就能打开。
2. 第一次启动会自动弹出「四步上手引导」，跟着点一遍就会用了。
3. 想查题：把题目粘到左边「题干」框，按 Ctrl+Enter（或点「开始搜题」）。
   题目在屏幕上？点「截图识题」；题目在图片文件里？点「选图片」。

二、数据放在哪
--------------
默认放在：
    C:\Users\<你的用户名>\AppData\Local\QBank
（里面是 config.json 设置、qbank.db 题库和搜索历史。）

想让数据跟着程序走（比如放 U 盘里随身带），在这个文件夹里新建一个空文件：
    portable.txt
程序就会把数据写到自己旁边的 data 文件夹里。删除 portable.txt 即恢复默认位置。

三、这个程序会一直在后台跑吗
----------------------------
默认是的。局域网共享和 OCS 接口服务需要保持在线，所以点窗口右上角的 × 是
「收进系统托盘」而不是退出（右下角会出现一个鱼图标）。
- 双击托盘图标 = 叫回窗口
- 右键托盘图标 = 打开主界面 / 打开数据目录 / 退出题库工坊
不想这样的话：设置 → 4 · 使用偏好 → 窗口与托盘，把「关窗口时收进托盘」的勾去掉。

四、想配一个大模型（让 AI 也能答题）
------------------------------------
设置 → 1 · 模型与网络 → 添加服务商 → 选一个预设（DeepSeek / 硅基流动 / 阿里云
百炼 / OpenAI / 本机 Ollama / 自定义）→ 填 API Key → 点「获取模型」挑一个模型
→ 右上角「保存设置」。
不想花钱也可以接本机 Ollama，完全离线。只要本地题库里有这道题，不配模型也能查。

五、导入在线题库（OCS 配置）
----------------------------
设置 → 2 · 题库来源 → 在线题库（OCS 兼容），把 OCS 里的题库配置 JSON（或者
题库配置链接、Base64）粘贴进去，点「导入题库」。
导出的 JSON 也能直接粘回 OCS 脚本里用，两边格式是通的。

六、常见问题
------------
Q: 搜题总报「网络请求失败：目标计算机积极拒绝」？
A: 系统代理残留。关掉代理软件后 Windows 不会清掉代理设置，请求全被送去一个
   死端口。到 设置 → 1 · 模型与网络 → 网络出口，选「直连」再保存即可。

Q: 截图识题说没找到引擎？
A: 到 设置 → 3 · 图片识题 点「探测安装位置」。装着 Umi-OCR 的话会自动找到；
   也可以用 Windows 自带的 OCR（零安装）。

Q: 怎么把题库分享给同学？
A: 设置 → 2 · 题库来源 里有局域网共享的开关；双方在同一 Wi-Fi 下，一方开
   「对外提供题库」，另一方在「局域网共享」页搜节点就能查到对方的题。

Q: 怎么彻底卸载 / 清干净？
A: 这是绿色版，删掉整个文件夹即可。再把数据目录（第二节里的位置）删掉就不
   留任何东西了。
